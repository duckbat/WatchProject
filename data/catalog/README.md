# Reference catalog

Source: https://github.com/timepiecepedia/timepiecepedia-data (references.csv)
License: CC0 1.0, supplied alongside this snapshot.
Imported 2026-11-07: 40,753 unique brand/reference combinations from 48,603 CSV rows; 0 rows without a brand/reference excluded. Upstream coverage is incomplete and specifications are not independently verified. This is catalog metadata, not live pricing.

Image URLs point to external sources; image rights are distinct from catalog metadata. Missing/broken images show a watch icon.

Photo URLs repaired from the upstream JSON `image_url_source` field: 39,883 exact-reference originals. 870 records have no original photo URL. The old mirror paths are no longer used.

All catalogued dial/bracelet variants are selectable in the searchable detail-view picker; no first-eleven cutoff applies. For example, Rolex Datejust 126234 has 50 configurations, including Palm, blue fluted motif, diamond-set versions, and Jubilee/Oyster bracelets. Stable full-reference IDs and original images are preserved. This exposes the imported catalog; it does not claim every historical or aftermarket dial is documented.
